# IISPPR Landing Page Project 🚀

## About
This project is being developed as part of our internship collaboration for IISPPR.

The goal is to create an engaging and user-friendly landing page that helps attract visitors and improve interaction through modern UI elements and lead-generation features.

## Features
- Responsive landing page design
- Interactive popups
- Advertisement sections
- Google Form integration for user responses
- Clean and modern UI
- Team collaboration using GitHub

## Tech Stack
- HTML
- CSS
- JavaScript

## Team Workflow
Each contributor will:
1. Create a separate branch
2. Make changes and commits
3. Push changes
4. Create a Pull Request
5. Merge after review
